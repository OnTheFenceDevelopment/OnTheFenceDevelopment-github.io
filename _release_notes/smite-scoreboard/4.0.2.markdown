## 4.0.2 - Bugfix Release
Automated crash reports were received indicating an issue when users were attempting to take a players photo but hadn't granted the Camera permission.

This resulted in the app hanging/freezing and then exiting, losing all player entry up to that point.

This release fixes the issue for both Android and iOS versions.

Apologies for any inconvenience this bug may have caused.
